# Layer 9 combo matrix — scripts/bin_target_combo_gate.sh (issue 231).
# One combo per line:  <comma-separated features> | <reason>
# Lines starting with '#' and blank lines are skipped; every named feature
# must exist in the ROOT [features] table (a renamed/removed feature reds its
# stale row — never a silent skip).
#
# THE RULE: a commit that widens a cfg to a union (any(A, B)) adds the
# breakable-arm row HERE in the SAME commit — the posture that turns the
# widened side ON while the strict producer's other requirements stay OFF
# (the fix(230) shape: consumer any(kat_service, points) + producer
# all(kat_service, latent_retrieval) breaks only at points+score_bench,
# masked by --all-features through the kat_service arm and compiled out at
# default/singles). A row earns its place when the posture carries a NEGATIVE
# arm (some feature OFF that --all-features turns ON) or reproduces a
# historical break.
#
# EVERY ROW NAMES latent_retrieval: the root bins' required-features demand
# it (cargo-refine + corpus_diagnose), and a posture without it compiles no
# bin at all — cargo skips the targets silently and the combo is a green
# no-op (the gate reds that shape too, but the rows are pinned correct so
# the gate's compile half always reaches real bins).
