## GOAT candidate — criterion test

**`merge-returning-batch-sorted-into-aged-queue`** (#7), the only benchable candidate:

1. **Benchable** — rust_perf_bench Pareto validator + alloc axis; comparison-count and alloc-count fixtures both natural.
2. **Exact semantics** — merge by `turn_ordinal` with stable left-preference on ties (`queued <= returned`); integer-exact, G1 bit-identical trivially.
3. **Magnitude story** — k ≪ n serving regime: O(k log k + n) vs O((n+k) log(n+k)) comparisons, plus single-allocation merge; k=32, n=10 000 → ~10.2 k vs ~133 k comparisons (~13×). Modest but mechanism-level.
4. **Deterministic** — pure function of (queue, returning batch); no timing.

Passes all four → GOAT-lead. The headline DECISION-CONTENT rule (#1) fails criterion 1 for a **domain reason** (overlap serving latency lives in a device runtime the validator cannot host) → per-rule `NotBenchable` annotation, never a demotion (the dial9 two-class split; Batch 136 precedent).
