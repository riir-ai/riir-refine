## TL;DR

SparseRead is a **control plane in front of an agent's read tools**: `artifact → Read Gate → Reader Backend → EvidencePack → refine/verify/stop`. It cuts agent tokens up to 92.9% / wall time up to 89.0% while preserving or improving task quality in 29/30 settings — with no model changes, no compression model, no training. Three mechanisms, each independently modelless: a **Read Intent Protocol** (structured per-access intent + per-slot coverage + episode state + fingerprint invalidation), **Adaptive Reader Backends** (acquisition config chosen by `argmin cost s.t. Wilson-LCB reliability ≥ τ`, fail→full view), and a **Budgeted Read Gate** (episode budget `E ≤ L` checked BEFORE delivery, faithful full-view fallback, native-relative exposure bound ≤ 2L — ski-rental-style). For the rulewright this is the missing discipline around its read lane: our admission gates (pregate, span_shape_dispatch, QUERY_TEXT_CAP) are all single-axis and stateless — no coverage record across a fix campaign, no cumulative budget with a faithful fallback. Filed as Issue 233 with proof paths.

**Distilled for riir-refine (modelless, serving-time):** the transferable shape is *processing scope ≠ model exposure, bounded by an online budget with a faithful fallback, tracked under a per-episode coverage record keyed to a content fingerprint* — all computable with BLAKE3, Wilson intervals, and a byte counter. Zero GD.

## 1. Paper core findings

- **Over-reading is measurable:** external observations are 60–80% of agent-trajectory tokens (prior work); unmodified agents spend up to 17.3× more tokens than gated reading with no quality gain. Annotated supporting evidence covers only ~2.9–5.8% of source content in long-doc QA.
- **Three distinct quantities:** *processing scope* (what a Reader computes over — may be the whole table), *model exposure* (what enters context — may be just the result + provenance), *evidence coverage* (which intent slots have support — never sufficiency; the AGENT decides to answer/refine/verify). Reducing exposure never requires reducing scope — the Reader-operations axis (`scan all rows, expose the sum + row count + source`).
- **Read Intent Protocol:** per-access intent (`want`: fact/count/verbatim/table/schema/list × `scope`: new/narrow/expand/verify × 5 actions scout/focus/collect/refine/verify), session-intent fallback for underspecified accesses (→ bounded Object Preview), SHA-256 artifact fingerprint invalidates episode evidence on change, per-slot coverage records inspected-vs-unresolved. Measured: repeated reads 4.8 → 1.5/task (−68.8%); untraceable evidence 28% → 8%; effective verification 37% → 89%; missing-evidence failures 25% → 5%. Protocol repair alone cuts total tokens 2.1–6.3×.
- **Adaptive Reader Backends:** a config = Reader × location method × exposure form; selection `r* = argmin Ĉ(r|g) s.t. p̂_valid(r|g) ≥ τ` with **τ = 0.6 = lower end of a 95% Wilson interval** over annotated dev requests (binary evidence-success criterion; <20 requests per group → default config, fallback on miss). Cost adapts from behavioral signals (repeated access, escalation); **reliability is calibrated once and never adapts to outcomes** — correctness never rides behavior. Location-method ablation: lexical 39.5% hit @ 780 chars vs BM25 60.1% @ 1,497 vs hybrid 65.3% @ 1,490 — method quality is measurable and artifact-dependent.
- **Budgeted Read Gate:** episode budget `E ≤ L` where `L = |f(o)|` = the fixed cheapest faithful full view. Checks the estimated AND serialized size BEFORE delivery; a batch that cannot fit intact is **withheld** and the full view delivered instead — evidence is never truncated mid-meaning. Total episode exposure ≤ 2L (Prop 4.1, tight; ski-rental lineage). Check-after-delivery overshoots to 2.10–2.33L; check-before keeps 1.62–1.93L. On fallback, earlier sparse observations are RETIRED from later prompts (prefix-cache loss is accepted and disclosed). Regime boundary: forced sparse reading on wrong-shaped tasks costs +309%/+210% tokens; the gate's bypass (native-fit controls) saves instead.
- **Integration shape:** MCP server (8 tools) + framework hooks (PreToolUse/PostToolUse) that enforce/advisory-gate native reads; a one-time-block rule downgrades blocked → advisory so the model can always proceed; SKILL.md guidance is advisory — **enforcement lives in the core, never in model compliance**.
