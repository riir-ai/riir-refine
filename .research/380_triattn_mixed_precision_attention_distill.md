## Mechanism map (what the repo does)

Per-head QK tiles are assigned to SKIP / 4-bit / 8-bit via **two diagonal-distance boundaries** `(w8, w4)` — O(1) policy storage per head, independent of context length. Offline: `calibrate.py` measures each boundary pair's error as **O-projection Gram-weighted normalized output error** (`calibrate.py:57,63` — `deltaᵀ·Gram·delta / energy`), over a ~66-config grid (`calibrate.py:18`); `allocate.py` traces a **Lagrangian λ-sweep frontier** (`argmin(err + λ·cost)` over λ ∈ logspace(-9,1,400) per head) and picks per cost-fraction points under a SHARED mean-cost budget (`allocate.py:33` — cost from closed-form boundary tile counts with a measured 4-bit cost ratio `c4=0.905`, `allocate.py:24`); `select.py` gates candidates on **per-length-group NLL Δ ≤ 0.01 AND KL ≤ 0.002** (`select.py:16-17,67`, buckets 32K/64K/128K at `:20` — never pooled), cheapest passing point wins, loud failure when none passes. Runtime prefill (`prefill_sm89.cu`): a four-pass precision ladder through ONE online-softmax accumulation — QK-int8×PV-f16 (nearest diagonal tiles) → QK-int8×PV-int8 → QK-int8×PV-int4 → QK-int4×PV-int8 (far band) — IMMA tensor cores throughout (`mma.sync s8s8s32 m16n8k32` / `s4s4s32 m16n8k64` for QK, `u8s8`/`u4s4` for PV), the `0x4B400000` magic-anchor int→float epilogue, per-tile 4-scales, `__maxnreg__(128)`. Q and K quantize per-row/per-sub-block absmax AFTER a **shared fixed-sign Hadamard rotation** (`rotate128`, pinned sign constants, 1/√128). Prefill-quantized K/V are REUSED as the decode cache: ragged per-head slot layout (`decode.py:41` cumsum slot compaction), bit-packed `kinfo` tile descriptor (rowmask | is4 | slot<<9, `decode.py:43-44`), `NEAR_V8=16` near-field window (`decode.py:9,20` — the latest 16 decode rows stay 8-bit), occupancy-driven wave partition (`decode.py:54`, `common_host.cuh:89`), split-K decode partials + merge kernel, BF16 decode tail (max_tail 256).
