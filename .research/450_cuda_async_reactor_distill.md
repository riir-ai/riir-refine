## What the module is

One process-wide reactor thread replaces per-completion `cuLaunchHostFunc` callbacks: a registration enqueues `cuStreamWriteValue32` into a slot of pinned host memory (1024 slots, `CU_MEMHOSTALLOC_DEVICEMAP` device-alias), and the scanner scans the armed-slot bitmap with plain memory loads — "The wakeup cost amortizes across all in-flight pipelines instead of paying a driver-thread hop per pipeline" (reactor.rs:9-14). The handoff (`SlotTable`) is CUDA-free, SPSC payload cells behind an active bitmap, mutex-guarded free list, "model-checked under `loom`/`miri`" (reactor.rs:16-19). Completion is runtime-selectable (`CUDA_ASYNC_HOST_SYNC=spin|block` forces the legacy host-func paths; "The explicit modes bypass the reactor so all three completion paths can be A/B'd from a single build", device_future.rs:201-208) — a positive instance of the house env-switch/A-B posture, recorded never landed.
