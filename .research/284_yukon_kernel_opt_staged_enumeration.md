## Group 1 — GDN eager/L8/L8V + state-clear + top-k-select (14 candidates: 8 own + 6 riders)

### Own rules

1. **`lane-permuted-column-reduce-same-butterfly-tree-bit-identity`** — A, **A−**. The incumbent eager GDN ends every column's dot in a 5-step warp butterfly (40 shuffles/token); the L8 arm permutes the lane→row map (8-lane group per column) so the first two butterfly steps become an explicit register fold and the rest run inside the 8-lane group — the same leaves in the same tree, **bit-identical**, 40 → 6 shuffles/token (source-stated). Bit-identity is load-bearing: the lazy-rollback per-warp checksum reads the stored base in the OLD layout order, so both arms must produce identical checksums. Regime gate `GDN_L8_MIN_TOKENS 17` (prefill class), env kill-switch `GGML_CUDA_GDN_L8=0`. Verified: kernel.cuh:498-505 (the lane-permutation comment), :530 (`__fadd_rn(__fadd_rn(p[0], p[2]), __fadd_rn(p[1], p[3]))`), :510. Kin: distinct from `register-resident-scan-state-one-kernel-layer-pass` (chunked MMA, argmax-stability contract — THIS is eager + bit-identity); instance of the `recurrence-prefill-exact-restructure-before-reformulation` doctrine (B114) with a new tree-preservation mechanism. CPU-testable oracle (fold-tree equality).
2. **`lazy-rollback-journaled-window-replay-replaces-eager-state-snapshots`** — G, **A−**. Eager rollback writes K full state snapshots (2 MiB/slot) where the next ubatch reads ≤ 1; the lazy arm journals final state + window base + per-token RAW inputs (k, v, g, beta) per block, replays W−r tokens bit-identically on rollback, and gates the replay on magic + window + budget (`2 + gridDim.z <= K`) + per-warp FNV checksum with EAGER-SLOT FALLBACK on any mismatch. Verify-sized arm skips slot 0 with a two-finite-float mark (`GDN_LAZY_NOFINAL`) chosen to survive the fresh-cell zeroing scale. Publish ordering: payload → `__syncthreads` → word/flag → `__threadfence_block` → magic LAST (magic is the commit point). Verified: kernel.cuh:55-66, :163-164, :198-199. Kin: distinct from `gdn-transition-replay-log-commit-many` (journals to COMMIT accepted tokens post-selection; THIS rebuilds a PRE-ROLLBACK state across ubatches, with checksum + fallback). Full ladder CPU-portable.
3. **`dead-destination-scale-elided-consumer-applies-on-load`** — C(+D), **B+**. Fallback runs the scale eagerly pre-kernel on any guard mismatch; the non-L8 arm hard-asserts; the lazy-replay arm REFUSES the record when the row is to be scaled. Verified: gated_delta_net.cu:267-269, :278; kernel.cuh:569, :630. Kin: distinct from `constant-scale-folded-into-upload-copy` / `per-row-scale-folded-into-rhs-staging-tile` / `inplace-grad-accumulate-deferred-postscale` (defers to preserve accumulation; THIS elides because the write is dead). CPU-testable.
4. **`gate-activation-precompute-pass-token-threshold-gated`** — B(+D), **B+**. Cross-warp transcendental redundancy (every column-warp recomputes the same per-(token,head) gate): two precompute passes — exp(g) at n_tokens ≥ 32, raw-gate activation (softplus overflow branch + sigmoid → g AND beta) at ≥ 64 — with the kernel templated `G_PRECOMPUTED` and `static_assert(!(RAW && G_PRECOMPUTED))` forbidding double activation. Kin: cross-warp redundancy + template pairing is new vs the hoist family (`hoist-group-invariant-scale-out-of-word-loop` etc.). CPU-testable.

## Group 3 — MMQ j16/j128/ptq1/dl (8 own + 8 riders)

Terminology from the source: **J** = the MMQ tile's activation-column count (J=16 decode posture, J=128 prefill posture; both bit-exact drop-ins for `mul_mat_q<PQ2_0, 16|128, false>` reusing the stock stream-K partition + fixup). **DL** = decode layout — a load-time PURE-PERMUTED copy of the weight (TM tile-major / WM warp-major) so each CTA's K range is contiguous.

### Own rules

23. **`magic-anchor-mma-exact-int-float-ffma-epilogue`** — B, **A−** — the batch's strongest portable candidate. The int8-mma accumulator initializes at 0x4B400000 (12582912.0f = 1.5·2²³); since |idot| ≤ 2²² the int32 result IS the float 12582912 + idot exactly — the I2F disappears. The j128 epilogue goes further: ndA = −12582912·dA is exact (dA ≤ 11 significant bits) and `fma(D_f, dA, ndA) = RN(idot·dA)` — two FFMAs replace I2F+FMUL+FFMA, bit-identical over an EXHAUSTIVELY TESTED domain (all fp16 dA × all idot, honest restriction: dA > 0 or (+0, idot ≥ 0)); the j16 subtract-form is the unconditional-exactness pole. CORPUS GREP ZERO: `12582912|0x4B400000` unowned. Verified: mmq-pq2-j128.cuh:16-21, :231, :262-263; mmq-pq2-j16.cuh:24, :119.
