### What EXL3 is here (one paragraph, from the code)

ExLlamaV3's trellis quantization as checkpoints store it: a quantized linear (K, N multiples of 128) is `trellis int16 [K/16, N/16, 16*bits]` + scales (`suh/svh fp16` or packed sign words) + optional bias + a codebook marker (`mcg` = 0xCBAC1FED, `mul1` = 0x83DCD12D, absence = "3inst"). Each 16×16 tile = 256 values in a circular bitstream of `256*bits` bits, read MSB-first within little-endian 32-bit words; value *p* is the 16-bit window ending at `(p+1)*bits` (half-integers alternate KA/KA+1, extra bit on odd positions; half-integers require mul1). Codebook decode is closed-form integer ALU → fp16 (3inst: `s*89226354 + 64248484`, mask/flip, byte_perm, one hadd2; mul1: `__dp4a` byte-sum + one hfma2). Widths 1–8 bits + 1.5/2.5/3.5 (mul1 only). Layer: `y = ((((x·suh) @ H_K) @ W_q) @ H_N)·svh + bias`, H = 128×128 Sylvester Hadamard/√128.
