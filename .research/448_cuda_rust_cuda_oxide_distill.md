## What the source is

NVIDIA's official CUDA platform for Rust. Three legs:

1. **cuda-oxide (SIMT)** — a custom rustc codegen backend (pinned stable 1.99.1 + rustc-dev/llvm-tools via `cargo oxide`) producing PTX from safe Rust kernels; device crates (`cuda_device`) expose mbarrier/TMA/tcgen05/TMEM/CLC/cluster intrinsics; host crates (`cuda-core`, `cuda-bindings`, `cuda-async`) carry contexts/streams/buffers/lazy-ops.
2. **oxide-proofs-preview** — compile-time Lean 4 verification: `#[launch_contract(requires = ...)]` host launch preconditions + `#[verify(no_oob_idx, no_data_race, disjoint_writes, writes_all_elems, uniform_barriers, tmem_lifecycle)]` device safety clauses; the compiler pauses at `PostMem2Reg` MIR (pre-unroll, checks still present), transcribes 1-to-1 into Lean, discharges VCs via `omega` (0 `sorryAx`), then ERASES the proven `mir.assert` bounds checks in memory before LLVM→PTX. TCB honestly enumerated: mir-importer/mem2reg, the lean-exporter (fail-closed on unsupported ops), mir-lower/LLVM/ptxas, host launch checks. Claimed zero-overhead: 2,118.4 TFLOP/s verified vs 2,118.1 unsafe at 16384³ on B200 (100.01%).
3. **cutile-rs (Tile)** — proc-macro JIT Tile model (Rust → Tile IR → cubin), NumPy-shaped; 346 `.rs` files, thinner mining surface (compiler-driven mapping; the decision content lives in the compiler, not user kernels).

The mining surface is the SIMT examples (`gemm_sol` 6,881 lines — an eight-phase GEMM ladder from tiled to 4-stage CLC multicast; `tcgen05` 1,269 lines — the sync-primitive tour) + the proofs-preview contract split. Zero `todo!()`/`unimplemented!()` in the mechanism files; bench tables + a live cublasLt baseline harness ship in-repo (good measurement hygiene, cited as a rule candidate below).
