## What the articles establish

**Part 1 (algebra):** safe softmax is secretly associative via the online-softmax carrier `(m, d)` (Milakov & Gimelshein 2018): merge `m = max(m₁,m₂); d = d₁e^(m₁−m) + d₂e^(m₂−m)`, identity `(−∞, 0)`. Welford's `(n, μ, M₂)` (Chan/Golub/LeVeque parallel form) is the same shape — the author's own "side quest". FlashAttention's `(m, d, o)` carrier is a **twisted monoid**: one coordinate (the max) acts on the addition of the others via the `e^(Δm)` rescale — **transport of structure** ψ(m,D,O) = (m, D·e⁻ᵐ, O·e⁻ᵐ) over the plain direct product. **3HT (Gibbons 1996):** a loop computable as BOTH foldl and foldr has an associative combine guaranteed to exist, constructible from the two folds — "a test for when any loop is secretly associative". Stability is NOT free: exponents ≤ 0 ⇒ e^(s−m) ∈ (0,1], d ∈ [1,N], relative error ≤ (N−1)u/(1−(N−1)u); tiling never amplifies (each merge rescales by e^Δm ≤ 1). Quantization is many-to-one → transport does NOT apply; dequantization (affine) does. Base-2 twist (σ = s·log₂e affine ⇒ exp2) is legal and free via qk_scale — and then Part 2 measures it FLAT.

**Part 2 (lowering):** the scoreboard (RTX 5090, fp16, 4096 ctx): scalar 25959µs → tensor cores 612 → smem staging 511 (1.20×) → bank-conflict pad 315 (1.62×, "132M conflict replays → ~0") → C→A register repack 271 (1.16×) → Q hoist 233 (1.16×) → pipelining 222 (1.05×) → x4 drain pairing 219 (1.01×) → TMA 211 (1.04×) → **two independent softmax chains 206 = FlashAttention-2 parity**, ~80% of the tensor roofline. The autotuner's winning geometry (128 query rows, 4 warps, 2 m-atoms/warp) converged on Dao's hand-picked FA-2 constants; FA-2's own source comments document the manual sweep "line-for-line like the autotuner's fork table". TMA wins the LSU count (3.31M vs 4.36M) but measures ~flat — transport is not the bottleneck, the tensor pipe is.

**The four refusals (the measurement-refused content the queue values):**
1. Warp-scoped barrier (~0µs): `__syncthreads` → `__syncwarp` on the C→A handoff moved nothing.
2. Fast exp (~0µs): `__expf` (one FMUL + `MUFU.EX2`) and the base-2 qk_scale fold both flat across TWO kernel structures — the kernel is tensor-bound, so an SFU-side move has no headroom; FA-4's FMA-emulated exp answers a DATACENTER-Blackwell imbalance (tensor doubled, SFU stood still).
3. Deeper rings d3/d4: occupancy loss beats extra overlap at every geometry.
4. Warp specialization 213 vs 206µs: WS without asynchronous MMA (wgmma sm_90 / tcgen05 sm_100) is a pessimization; consumer Blackwell has TMA but not the async tensor instructions, so "the honest frontier statement for consumer Blackwell is FA-2 parity".

**FA-3/4 hardware analysis:** FA-3 = Hopper (wgmma async MMA + TMA + deep WS pipeline); FA-4 = B200 (tcgen05 + TMEM 256KB + 2-CTA MMA). None of that silicon exists on consumer parts — portable-sounding FA-4 ideas (FMA-exp) fail for limiter reasons, not silicon-absence reasons.
