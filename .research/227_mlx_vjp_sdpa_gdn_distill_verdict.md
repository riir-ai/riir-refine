## What they are

Training/backward-side kernels, NOT serving movement:

- **#4563 (SDPA VJP):** the attention backward expressed as **a sequence of tiled `steel_matmul`s** with ONE small elementwise kernel (`sdpa_vjp_ds`: `P = exp(scale·S − lse)`, `dS = P⊙(dP − δ)·scale`) between them, a tiny `sdpa_vjp_odo` delta kernel (`δ[i] = Σ_d o·dO` via `simd_sum`), and a reduce kernel that folds the GQA head-group sum + set/add accumulation. Source-measured (M5 Ultra): causal up to **2.8× speedup**, memory better in EVERY config up to **24×** (24.63→1 GiB @B=1; 97→4 GiB @B=4). **The load-bearing negative: a specialized fused kernel LOST** — "it requires more compute: the attention matrix is never materialized and instead is computed, implicitly, twice. Expressing the VJP instead as a sequence of tiled matmuls, using steel, gives a large memory reduction and speedup." (The fused attempt is the CLOSED PR #3241 — the negative arm has its own provenance.) Regime exception disclosed: `(head_dim=256, n_qh=24, n_kvh=4)` can be SLOWER than fallback; memory still wins.
- **#4565 (GDN VJP):** two backward paths — sequential (pure Metal, `gated_delta_vjp_seq`) and chunked NAX (`gated_delta_vjp_fused_nax` over MetalPerformancePrimitives `matmul2d`). Chunked is **1.4–6.3× the sequential** and **9–79× the ops fallback** (Hk=16/Hv=32/Dk=Dv=128, B∈{1,4,8}, T 8..4096). NAX is gated by `is_nax_available()` (**M5-class silicon — our M3 Max does NOT have it**; on M3 the VJP is sequential-only).
