## Tasks

- [ ] **T1. Consumed-window ledger + re-validation refusal** (the strongest item; L2's modelless reading). Law: a selection may be re-judged only on outcome windows its selection did not consume — self-scoring on consumed data doesn't stall, it INVERTS below baseline (T³: own-half testing −0.158 at epoch 1 → +0.046 worse than the record script at epoch 5). Today `select_best_candidate` + Elo/BetaPosterior re-read the same recorded-outcome store that shaped them — the adaptive-reuse pattern. Delta vs the closest shipped cousin (adoption gate's held-out 32-case window): the ledger of WHICH windows each selection consumed + a REUSE COUNTER (the paper shows reuse count itself is the poison variable, a non-monotone valid→poisoned curve — a boolean "burnt" flag misses it), and the stale-window verdict is UNDECIDABLE, never folded into a refusal. G1 fixture: synthetic outcome store + pinned selection replay — a rule re-scored on its own selection window refuses/flags; a disjoint window proceeds; repeated self-scoring degrades a synthetic truth metric and the probe fires by the k-th reuse. Feature flag `consumed_window_ledger`, default-OFF, feature-off byte-identical.
- [ ] **T2. Half-split agreement readout** (gradient-free analog of T³'s ⟨∇L_A,∇L_Q⟩). Build the corpus-is-the-model scorer from half A only and half Q only, run both over a neutral probe set, read pick-agreement/flip-rate (the normalized agreement signal) + calibrated-confidence divergence. Deterministic, BLAKE3-digestable, zero training; harness-lane report-only beside the existing cal/test arenas. Testable prediction from the paper's L1: this signal predicts later measured holdout deltas ONLY in repeated-consultation surfaces, and nothing on 1-pass ones — the correlation cell IS the gate. Signal-diff vs the agreement class first (query-by-committee disagreement = class cousin; the delta here is corpus-derived predictors over a shared probe set + the L1 regime gate). G1: pinned agreement digest per corpus (determinism).
- [ ] **T3. Multiplicity-gated arming predicate** (L1's ordering law). Holdout-flavored arms fire only when the surface's encounter multiplicity ≥ a locally measured knee — sigmoid-gated over a counter, never softmax; the knee is MEASURED per surface, never imported (T³'s 4-pass knee is a training-surface constant). Boundary result included in the fixture: quorum/chain surfaces are 1-pass by construction — L1 predicts holdout machinery buys nothing there; the family is fenced OUT of the chain plane by the same law that arms it here. G1: truth-table fixture — multiplicity < knee → byte-identical unarmed behavior; ≥ knee → armed.
- [ ] **T4. Source-case-first gate** (L3's law: a candidate that does not improve on the data that generated it carries no held-out value — zero-length/random/uphill trial steps all landed in noise). Cheap source-case check gates the expensive held-out verification: a drafted fix must resolve its trigger finding BEFORE the compile-gate spends the "Q half" (the workspace recompile). G2 is the prize: wasted compile-gate rounds are compile-minutes; preregister the bar before the cell. Depends on T1's ledger for the window hygiene.
- [ ] **T5. Two-signal composition** (L5: holdout signal ALONE was +0.021 WORSE than nothing). A lone held-out window must never single-handedly reverse an armed lane; the committed decision composes arming-time evidence + window verdict in one decision artifact, and candidate probes evaluate in side state (T³'s φ is throwaway — mutate the serving artifact only via the composed decision). G1: fixture — a lone-window reversal of an armed lane is refused absent corroboration; a corroborated one proceeds.
