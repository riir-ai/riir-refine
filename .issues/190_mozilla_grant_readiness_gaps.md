Mozilla's Human-Scale AI Incubator ($300K/12mo → $500K/3yr, non-dilutive) fits cargo refine's modelless, consent-first, local-first design — but the application fails eligibility today on three axes: private source vs "work in the open", token-plane posture vs charitable purpose, and zero external product-community evidence. This issue lists every adjustment, in deadline order. Post-consult items (after Mozilla answers, expected before Nov 12 info session / by email) are marked.

## Tasks

- [ ] **T1 (owner gate) — Openness amendment — decide by 2026-11-07.** Decide: open the modelless core (corpus format + embedder + drafter + pruner + self-evolve) under MIT/Apache-2.0 with a dated plan (proposed: months 1–3 of the grant term; extraction repo layout draftable on request). This amends [Research 003](../../katgpt-rs/.research/003_Commercial_Open_Source_Strategy_Verdict.md)'s "never publish source" for the charitable core only — KAT/commercial surfaces may stay private. Without G1 the application is dishonest; with it, "Small+Intentional+Tailored" is fully shippable.
- [ ] **T2 (owner gate) — KAT freeze for the funded scope — decide by 2026-11-07.** Grant materials and the charitable build carry: no tokens, no pay/lease/purchase lanes, no soft-gate refusals, no KAT marketing. Code stays; scopes change. Decide the freeze mechanics (env kill-switch vs separate charitable build profile vs copy).
- [ ] **T3 — Evidence pack (executable now).** Collect: GitHub releases download counts for the public dist repo (`gist-rs/cargo-refine`) via releases API; dist repo + tap + bucket stars/issues; internal-usage stats from our own benches (batches run, heal rates from `.benchmarks/score_history.jsonl`); the "default dev-loop tool across a 32-repo production workspace" deployment story with links to the public repos that consume it.
- [ ] **T4 — Pre-application pilot soft launch (time-boxed).** Publish a call for 10–20 external pilot users via Rust community channels (r/rust, URLO, This Week in Rust submission) framed as "free, offline, modelless clippy healer — help us test". Capture sign-ups as early product-community evidence. Honest risk: 2.5 weeks may yield few sign-ups; the application can say "recruiting now" with the channel receipts.
- [ ] **T5 (owner gate) — Receiving entity / fiscal sponsor — decide by 2026-11-07.** Determine what can lawfully receive funds from a US 501(c)(3): gist-rs registration status, owner residency/tax picture, fiscal-sponsor shortlist (e.g. Software Freedom Conservancy, Hack Foundation/Open Collective, SPI) + their docs requirements. Needed for the full-application stage (shortlisted applicants only) but must be knowable at submission.
- [ ] **T6 — Website/public-copy audit.** Sweep our public surfaces (dist repo README, installers' landing copy, refine.riir.ai if live) for commercial/token claims that contradict the charitable framing; adjust per T2's decision.
- [ ] **T7 — Consult email send + info session.** Send the drafted email (in [`../.docs/01_orientation/mozilla_grant_readiness.md`](../.docs/01_orientation/mozilla_grant_readiness.md)) to `incubator@mozillafoundation.org` by ~Nov 7: (a) two-proposals-one-team question, (b) entity/fiscal-sponsor documentation, (c) openness-timing acceptability, (d) crypto-free scope requirement. Attend/register for the Nov 12 info session (17:00 UTC).
- [-] **T8 — Final application prose (owner-voiced).** Write the submitted answers in the owner's own voice (Mozilla AI policy). Deferred until: T1/T2 decided + T7 answers received; target Nov 17–19; agent text stays source material, never paste-ready.
- [ ] **T9 (post-consult) — Scope decision.** If Mozilla answers "one proposal per team": refine is primary (readiness playbook §2); rethink's community narrative folds into ours and [rethink Proposal 005](../../riir-rethink/.proposals/005_mozilla_human_scale_ai_incubator.md) is parked. If "two welcome": both submit; coordinate calendars, not content.
- [ ] **T10 (gate for T8) — No-submit-by-default check — 2026-11-17.** Mozilla excludes "technologies without users, contributors, or another meaningful signal". Do NOT submit unless at least ONE of: (a) ≥1 external user/contributor signal exists by Nov 17 (pilot sign-ups from T4, installer downloads with issues/stars, an external contributor PR), or (b) Mozilla's consult answer (T7) says internal deployment at scale counts as a meaningful signal. If neither: hold the submission, keep the packet, re-target the next cohort. This gate blocks T8.
