## The population, honestly

- The frozen `cases.jsonl` carries gate flags + per-candidate `blake3_12`
  but NO candidate texts; the texts were regenerated by `--arm POOLTEXTS`
  (the harvest's exact classify → warm sequence, frozen successes) and
  pinned per candidate against the frozen `blake3_12`.
- **The re-pin disclosure:** today's environment reproduces the frozen
  pools bit-identically on 1198/1494 rows; 296 rows drift (two runs
  byte-identical — the drift is systematic, not per-process
  nondeterminism; katgpt-core and the corpus moved since the 10-11
  harvest). On the pre-registered scored TEST population the drift is
  **9/666 = 1.4% — under the pre-registered 5% wall** — so the read ran
  on **657 pin-verified rows** (660 scored after strata: 660 deciding +
  1 none_gold; 5 dropped by the per-case pin). The 657 ≥ 621 (the T1.6
  gate N) still holds. The 296-row drift is the pool-birth environment
  moving under the frozen file — a re-harvest under today's env would be
  a NEW frozen population (a T1 re-run), not a repair of this one.
- Train-side, 291/828 rows were pin-dropped before training (the
  trainer's per-case pin); training consumed 1384 pairs over 537 cases.

## The trainer's own read (pre-read, train-side holdout, disclosed)

- Row-level holdout accuracy **1.0000 vs control 0.6053** (1384 pairs);

  collided with was never observed on holdout — recorded so the next
  generation's τ objective is chosen against a shift-aware surrogate, not
  this one.

## The invalid first execution (disclosed, ledger kept)

The first `--arm FROZEN` run (8.2 s, ledger
`/tmp/heal_frozen/frozen_ledger.INVALID_WIRING.jsonl`) served τ_prob=0.3
from a hardcoded server default — NOT the trainer's selected posture (the
trainer had selected τ=0; the default was a stale reading of an earlier
debug run's output). That run measured a different A1 (436/660 with 224
abstentions → DECLINE) and is **discarded as INVALID-WIRING, not a
read**: the pre-registered A1 never reached the wire. The class is closed
structurally — the τ now travel in the trainer-written, digest-checked
sidecar and the server refuses to boot without a matching one. No τ was
retuned post-read; the winning posture is byte-identical to the trainer's
pre-read selection.
