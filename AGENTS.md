## Documentation Shape

Files inside numbered folders have **no number prefix** (bare slugs); add a doc by dropping `slug.md` in the right folder + one line in that folder's index table. `README.md` (repo root) is the build surface; `AGENTS.md` is the authoritative repo-local context.

## Numbering Discipline

Issue, plan, doc, benchmark, and research numbers are **monotonic and never reused** — even after a file is removed per the noise-reduction rule. Before creating a new `.issues/` file, read `.issues/.highwater`, use `value + 1` as the number, and write the new value back. Same for `.plans/`, `.docs/`, `.benchmarks/`, `.research/`, and `.distill/` (the distill-program rolling resume state — edit-in-place per batch, NOT one file per batch). One counter per directory, enforced (Issue 069 T3); katgpt-rs `scripts/numbering_drift_sweep.py` covers this repo (sweep-covered, not per-push-gated); the standing fix for a collision is renumber + citation rewrite, never a silent reuse.

Research-note shape: `.research/` notes are born-complete distillation records, not task trackers (no `- [ ]` checkboxes — pending work lives in `.issues/`, the SKILL.md mining queue, or the feeding plan). Every new note carries a `**Status:**` line — `RECORD` · `DISTILLED — pending owner decision` · `NEGATIVE`; a later-filed delta gets a one-line status update pointing at the issue/commit.
